## 1. 概述与定位

### 1.1 一句话身份

塞舌尔是四地点里的**印度洋代表**：花岗岩巨石 + 双层海水 + 近顶光硬阴影（回源 `water-lighting-params.md` §1 基调表第 4 行——**唯一热带、唯一三段水深、太阳接近天顶**）。玩家在这里的身份不是建筑师也不是灯光师，是**垒石人**——不造房子、不织光网，把天然圆石一块块垫稳、堆高，看石缝里长出植物、象龟来栖。

| | 泉州「连」 | 圣托里尼「凿/悬挑」 | Cape Cod「照」 | **塞舌尔「叠」** |
|---|---|---|---|---|
| 空间维度 | 水平 · 线 | 垂直 · 向外 | 水平 · 面 | **垂直 · 向上** |
| 判定类型 | 连通链 BFS | 锚固距离 ≤3 | 覆盖（距离+遮挡） | **接触面比 vs 层高阈值** |
| 是否有硬限制 | 无 | 悬挑 >3 不可放 | 无 | **摇石上方不可叠**（回源 `location-gameplay-design.md` §3 对照表） |
| 玩家心智 | 建筑师 | 崖壁开凿者 | 灯光师 | **垒石人（重心与配重）** |

四地点里唯一「以自然物为建材、以重力为对手」的地点。**区隔成立**：与圣托里尼同属垂直但方向相反——「一个向外悬空，一个向上叠稳」（回源 `location-gameplay-design.md` §2.4）。

### 1.2 真实地理 / 文化锚点（回源 `location-gameplay-design.md` §2.4）

- **Anse Source d'Argent**（拉迪格岛）：世界上被拍得最多的海滩之一——巨型圆花岗岩 + 白沙 + 绿松石水
- **海椰子（Coco de Mer）**：塞舌尔国宝，世界最大的种子，仅普拉兰岛五月谷（Vallée de Mai）原生
- **Takamaka（红厚壳）**：海滨标志性大树，向海倾斜生长
- **象龟（Aldabra Giant Tortoise）**：塞舌尔的国家象征
- **Anse Lazio**（普拉兰岛）、**Anse Intendance**（马埃岛）
- **克里奥尔文化**：木质 + 茅草顶的 Creole 小屋
- ⭐ **地质签名**：花岗岩岛是全球罕见的**大陆碎片型**（冈瓦纳大陆裂解残留，约 7.5 亿年），与圣托里尼火山岛在地貌 / 色彩 / 成因上互为反义词——宣传上「**火山岛 vs 大陆碎片**」是一组现成的对照（回源 `location-gameplay-design.md` §2.4）
- 📌 候选池预留区隔：**叠（塞舌尔）= 重心平衡；砌（马耳他）= 构件承重咬合**；若未来做马耳他，至少与塞舌尔间隔一款（回源 `location-gameplay-design.md` R-7）

### 1.3 游戏内地形建议（回源 `location-gameplay-design.md` §2.4「地形特征」）

| 项 | 建议值 | 备注 |
|---|---|---|
| 岛形 | **中央花岗岩低丘 + 环岛白沙滩 + 浅礁泻湖** | 与泉州「湾 + 屿 + 滩涂」、圣托里尼「阶梯陡崖」、Cape Cod「沙丘半岛」都不同。⚠ 概念图为**环礁式中央潟湖**构图，与源文档岛形描述存在偏差——✅ **SY-D-10 已裁定（2026-09-25 Benja）：按 LGD 文字为准**，概念图仅作俯视双层水机位参考（见 §8） |
| **初始地形自带 20–40 块随机散落巨石** | ⭐ 关键 | 玩家的「素材库」与「天然地基」。零门槛起步——第一件事就是往现有巨石上继续叠。**这是塞舌尔成本能被压住的关键**：同时解决 ① 玩家从哪开始 ② 第一分钟就有事做 ③ 巨石即天然地基，省掉地基建材 |
| 沙滩材质 | 白沙替代草地（✅ **SY-D-2 已裁定（2026-09-25 Benja）：采美术档 `#F0E4CC`**，LGD 旧值 `#EDE4D0` 随其 v2.6 作废留档，见 §8） | 热带岛地表是沙不是草 |
| 垂直范围 | **维持 -4~20** | 巨石堆 8–12 层 ≈ 12 格，够用，**不需扩展**（回源 §2.4 表） |
| 建材上限 | **维持 12000** | 巨石堆叠受稳度约束、数量天然有限，不随圣托里尼升 16000（回源 `location-gameplay-design.md` R-10） |

> ⭐ **地形就是玩法**：泉州的地形逼玩家「连」，Cape Cod 的地形逼玩家「照」，**塞舌尔的地形自带「第一块石头」**——巨石散落 = 上手零门槛与「向上」挑战的起点合一。

## 2. 玩法链：「叠」的一次登顶

> 泉州的链条是**一条线**，Cape Cod 是**一个同心圆**；塞舌尔的链条是**一座塔的自下而上**——讲的是「**一堆乱石被一双手垫稳，最后稳到长出生命**」：立 → 垫 → 转 → 收分 → 石缝生花、象龟来栖。

### 2.1 唯一机制：堆叠平衡判定（R1 · `location_mechanic` 本体）

回源 `location-gameplay-design.md` §2.4 R1（本节为规格化转写，公式与常量**逐字回源、零改动**）：

| 量 | 定义 | 回源 |
|---|---|---|
| `contact_ratio`（接触面比） | 每块石头**底面落在下方实心格**（地形 / 石 / 楔石）的格数 ÷ 底面格数 | §2.4 R1 |
| `n`（堆叠层数） | 该石下方到最近实心地面的堆叠层数 | §2.4 R1 |
| 稳度阈值 `T(n)` | **`T(n) = 0.30 + 0.05 × n`，上限 0.70**（n=1 → 0.35；n=3 → 0.45；n=5 → 0.55；n≥8 → 0.70） | §2.4 R1 |

| 判定 | 表现 |
|---|---|
| `contact_ratio ≥ T(n)` → **稳** | 静止，可继续往上叠 |
| `contact_ratio < T(n)` → **摇** | **缓慢摇晃动画（±1.5°，周期 2.4s）** + 石缝细碎落屑粒子 + 放置音偏闷 + **上方不可再叠**（全地点唯一的硬限制，回源 §3 对照表） |

> **这是「越往上越需要配重/平衡」的具体化——阈值随层数收紧。**
> ⭐ 稳度是**不显示的隐藏量，只通过视觉表现**——这是 R-1 红线在塞舌尔的落点（回源 `location-gameplay-design.md` §5 R-1）。

### 2.2 链条（五步 = 玩家的技巧成长曲线，回源 §2.4 R2 / 体验曲线表）

```
【1】立    （在初始散落巨石上试着叠第二块——有的角度放上去会「晃」）
      │
【2】垫    （楔石塞进石缝 → 每块 +1 格接触面 → 学会救「摇」的石头）
      │
【3】转    （巨石 4 向旋转，R 键——不同朝向重心不同，选朝向是一门手艺）
      │
【4】收分  （大石在下、楔石作顶石 → 自然金字塔形；越高越难，玩家自发学会收分）
      │
【5】稳    （石堆达到 N 层且全稳 → 石缝长出植物、象龟来栖——见 §2.3 落成高光）
```

- **全程不显示任何数字**：无层数、无排名、无纪录、无进度条（回源 §2.4 R4 红线 + §5 R-1）。
- **D-5 已拍板（Benja）：不显示堆叠层数**（选项 B）——「一旦显示层数，塞舌尔就变成挑战游戏，P1 崩」（回源 §7 D-5）。
- 30 分钟体验曲线与深度评估（★★★★☆）回源 §2.4「前 30 分钟体验曲线」表；**本地点首要风险 = 「高度诱惑」**，对策即 R4 红线（回源 §2.4 深度评估）。

### 2.3 落成高光：生态反馈（R4）

回源 `location-gameplay-design.md` §2.4 R4——当一座石堆达到 **N 层且全稳**（所有石头 `contact_ratio ≥ T(n)`）：

| 触发后发生什么 | 首次触发时的一句话提示（建议，随 §2.2 教学原则「学完即走」） |
|---|---|
| ① 石缝间**长出岩生海芋 / 蕨类**——绿色沿缝蔓延（**shader 遮罩动画**，非逐帧生成实例） | 「石堆站稳了，石缝里开始长东西。」 |
| ② 石堆旁**白沙滩上出现一只象龟**，缓慢爬行 | 「连象龟都来住了——它觉得这里稳。」 |
| ③ 石堆投下的**浓荫里出现一小片水洼倒影**——赤道强光的硬阴影在这里变成构图主角 | —（纯观感） |

> ⭐ **「石缝长植物 + 象龟来栖」是塞舌尔的落成高光**（回源 §3 对照表「落成高光」行），必须是**安静的仪式感**：反馈是「它长出了植物 / 有龟来住」——**生态反馈，不是数值反馈**，无音效奖励、无弹窗、无成就（回源 §2.4 R4 红线块）。
> **与泉州「灯火次第亮起」的刻意区隔**：泉州是**人造光的仪式**（时间序），塞舌尔是**生命的仪式**（状态序：稳 → 生）。线与塔、光与生命，两个动词各自的形状。

### 2.4 衍生玩法：天然石拱（R3 · 不占机制名额）

回源 §2.4 R3：两块等高巨石间距恰好 **2–3 格**且都「稳」时，顶上可放一块**横梁石**（**复用桥拱改色**）→ 形成天然石拱，对应 Anse Source d'Argent 的真实天然石拱。

- **它是「叠」的副产品，复用同一套接触面判定，不占 `location_mechanic` 名额**（回源 §2.4 R3 原文）。
- ⚠ **桥拱的复用用途在两份源文档间曾冲突**（天然石拱横梁 vs 栈桥）——✅ **SY-D-4 已裁定（2026-09-25 Benja）：双用途**，横梁为主（玩法语义）、栈桥为次（视觉件），见 §8。

### 2.5 引导（防看不懂，非压力）

- 新规则教学绑定建材：**第一次选中楔石时，建材栏下方浮现一句话**——「楔石塞进石缝，能让上面的石头站得更稳。」（此例句为 `location-gameplay-design.md` §1.4 的原文示例，本地点沿用）
- 巨石「摇」的表现（摇晃 + 落屑 + 闷音）本身就是引导——不需要额外的地面提示层。（设计侧判断，待实机验证后回填；若需追加提示层，材质走 `A-1` 族：`unshaded` + `fog_disabled` + `blend_mix`，回源 §5 R-4 / `quanzhou-seychelles-art.md` §5.0.1）

### 2.6 红线（防止滑向效率优化 / 挑战游戏）

| 绝不做 | 原因 |
|---|---|
| 显示层数 / 高度榜 / 最高纪录 | 「谁堆得高」= 挑战游戏，P1 直接崩（回源 §2.4 R4 红线；D-5 已拍板 B） |
| 象龟做成生产 / 繁殖 / 效率系统 | 隐性计时压力（回源 §5 R-3：泉州渔船、塞舌尔象龟若做「生产效率」玩家会感到「来不及」） |
| 摇石做成「倒塌 / 失败 / 重来」 | 无失败态（P1 硬底线）；摇的代价**只有「上方不可再叠」一条**，石头不消失（回源 §2.4 R1 判定表） |
| 巨石做出「范围升级 / 强化」数值 | 石头是自然物不是生产资料；稳度只通过视觉表现 |

## 5. 特殊机制：象龟与生态层（本地点的「生命感」承载）
