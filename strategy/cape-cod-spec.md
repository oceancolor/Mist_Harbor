## 1. 定位与主题

### 1.1 一句话身份

Cape Cod 是四地点里的**大西洋代表**：冷灰蓝 + 沙质半岛 + 大西洋长浪（回源 `water-lighting-params.md` §1 基调表）。玩家在这里的身份不是建筑师，是**灯光师**——不造实体造关系，布置光源、织一张覆盖整条海岸的光网。

| | 泉州「连」 | Cape Cod「照」 |
|---|---|---|
| 判定类型 | **线**的连通（邻接 + 水面可达 BFS） | **面**的覆盖（距离 + 高度差 + 一次射线遮挡） |
| 光的角色 | **结果**：连成了才亮，被动奖励 | **手段**：玩家主动布置光源 |
| 光的形态 | 点状、暖橙、**人间灯火** | 锥状、冷白、**导航光** |
| 玩家心智 | 建筑师（造实体） | 灯光师（造关系） |

四地点里只有这两款玩"光"。**区隔成立**（线 vs 面、被动 vs 主动），但两者排期上必须隔开（口径见 `location-gameplay-design.md` §4.5 / §4.9）。

### 1.2 真实地理 / 文化锚点

- **Nauset Light**（红白条纹，最上镜）、**Highland Light**（最老最高，崖顶）、**Chatham Light**
- **Three Sisters of Nauset**：三座曾并排的小灯塔，Cape Cod 独有奇景
- **Weathered gray cedar shingles**：海风盐雾风化成的银灰色木瓦，Cape Cod 建筑最标志性的质感
- **Cranberry Bog（蔓越莓沼泽）**：秋季"水收"时整片沼泽变血红色——全产品最强的季节视觉爆点
- Salt marsh（盐沼）、沙丘与 beach grass（海滩草）、龙虾笼与浮标（每位龙虾渔民有自己的浮标配色，靠颜色认领自己的陷阱——这是免费且真实的文化细节）
- **Stellwagen Bank**：世界级观鲸海域（鲸鱼观景台的依据，见 §2.4）
- **Eastham Windmill**：Cape Cod 最古老的木板风车（现有风车屋建材在这里找到真实身份，见 §2.2）

### 1.3 游戏内地形建议

| 项 | 建议值 | 备注 |
|---|---|---|
| 地貌形态 | **主沙丘半岛 + 沿岸低丘 + 大片沙质浅滩 + 低洼沼泽** | 与泉州「屿 + 滩涂」、圣托里尼「崖」、塞舌尔「巨石」三种空间难题都不同——**平而阔**，是「面覆盖」玩法的天然舞台 |
| 垂直范围 | 沙丘与沼泽高差小，**灯塔与观景台是仅有的制高点** | 「塔要立在高处才照得远」的落差感靠塔身自身高度 + 沙丘微起伏，不需要大幅扩展垂直范围（量级由美术 / 技术侧对齐） |
| 地表材质 | 沙丘草甸（现有草地 `8ab18c` 改色向灰黄绿，美术侧终定）→ 沙滩米白 → 沼泽灰绿 | 泉州滩涂（泥黄 `#8E9A66` 系）与本地的沙滩米白相接近——区隔靠**「沙白 + 草灰绿 + 冷灰蓝水」三色并置**，不靠单色（防撞车口径见 `quanzhou-spec.md` §11.2 末段，同理反向适用） |
| 潮间带 | 大片沙质浅滩 + 盐沼洼地 | 蔓越莓沼泽块的放置位 |

> ⭐ **地形就是玩法**：平而阔的海岸 = 覆盖判定一目了然、暗角一眼可读。泉州的地形逼玩家「连」，Cape Cod 的地形逼玩家「照」。

### 2.4 ⚠️ 灯塔光效的硬结论（本节是给工程侧的对齐口径）

**真实 `SpotLight3D` 不可行**（已知结论）：Compatibility 渲染器 per-mesh 光源上限全岛共享，光束数量一多必然爆预算、pop 闪烁——**这不是"省着用"能解决的问题**。

✅ **本文件的光效设计，全部按「贴片光斑」思路**：

| 层 | 做法 | 依据 |
|---|---|---|
| **光锥** | **半透明锥体 mesh（假体积光）**，走 **A-1 材质族**：`unshaded` + `fog_disabled` + **`blend_mix`** | 与灯火光斑贴片**同一次实现**（`MH-ENG-002b` 已含「Cape Cod 光锥」）；`fog_disabled` 使光锥不被雾吃掉——**雾越浓、光锥越"实"**，这正是「凉雾灯塔」招牌画面的成立机制 |
| **覆盖判定** | **纯数据计算**（距离 + 高度差 + 一次射线遮挡），与渲染完全解耦 | `location-gameplay-design.md` §2.3 R1；玩法完整性与真实光源数量解耦，即使零真实光源，玩法依然成立 |

## 3. 玩法链：「照」的同心圆

> 泉州的链条是**一条线**（航标塔 → 栈道 → 蚵壳厝 → 古厝，环环向前推进）；Cape Cod 的链条是**一个同心圆**——从塔出发向外铺开，讲的是**「一座孤塔守望的海岸，被光一寸寸唤醒」**：塔亮 → 人来了 → 港活了 → 整条海岸在光网里醒来。

### 3.1 链条（四环）

```
【1】高地灯塔        （立在沙丘高点；点亮即成为光网节点，光锥旋转扫掠）
      │  覆盖判定（塔的光锥覆盖到守望屋所在格）
      ▼
【2】守望屋          （灰木瓦小屋，置于光锥覆盖内；窗灯 + 炊烟）
      │  覆盖判定（光网覆盖到渔栈码头）
      ▼
【3】渔栈码头        （风化木栈桥伸入海面；灯笼 + 系泊渔船 + 龙虾浮标）
      │  覆盖判定（光网连片覆盖整个灰木瓦渔村）
      ▼
【4】灰木瓦渔村聚落   （成片的 2×2×2 小屋；落成高光 = 零暗角时刻）
```

- **判定方式**：全链只用**同一套覆盖判定**（距离 + 高度差 + 一次射线遮挡，纯数据）——链条不是第二个系统，只是覆盖结果的**分级表现**。Cape Cod 唯一的 `location_mechanic` 仍是「光锥覆盖」（R1），未超载。
- 与泉州的形态对照：泉州靠**邻接 + 水面可达 BFS**（线）；Cape Cod 靠**覆盖判定**（面）——判定语义完全不同，链条只是把「面」的进度按四个里程碑讲出来。

### 3.2 逐级"活起来"的表现（**全程不显示任何数字**）

| 环 | 触发后发生什么 | 首次触发时的一句话提示 |
|---|---|---|
| 塔点亮 | 光锥开始旋转，光斑扫过沙丘草，草浪随光斑方向压伏（纯观感动画） | 「灯塔转起来了，光会替你看着这片海。」 |
| 塔 → 守望屋 | 光束**第一次扫过**守望屋的瞬间，屋窗暖灯亮起、烟囱升起第一缕炊烟 | 「守塔人住下了，烟囱冒烟了。」 |
| 守望屋 → 渔栈 | 栈桥桩柱灯笼自岸边向海面**次第点亮**，系泊小船随浪轻晃 | 「渔栈通了，船进来了。」 |
| 渔栈 → 渔村 | ⭐ **落成高光「零暗角时刻」**：光网覆盖内的所有窗灯、浮标、灯笼**同时呼吸一次**（亮度统一涨落一个来回），随后稳定常亮 | 「整条海岸都醒了——雾里那张光的网。」 |

> ⭐ **「零暗角时刻」是 Cape Cod 的落成高光**，也必须做成**安静的仪式感**：没有音效奖励、没有弹窗、没有百分比达成。
> **与泉州「灯火次第亮起」的刻意区隔**：泉州是**线性仪式**（一盏一盏、0.15s/栋），Cape Cod 是**面性仪式**（一整片同时呼吸）——线与面，正好是两个动词各自的形状。

### 3.3 引导（防看不懂，非压力）

- 未点亮区域在夜间显示**极淡的暗角提示**（可选、默认关闭、可一键关）——与泉州微光箭头同一材质族（`fog_disabled`，见 §2.4）。
- 第一次点亮灯塔 / 触发各环时，建材栏下方浮现一句中文（见上表），学完即走。
- 覆盖热力图：**构图工具，不是评分**——夜晚或拍照模式下可显示（暖色 = 已覆盖，深蓝 = 暗角），不给分数、不给成就、不弹"100% 达成"，默认关闭。⚠ 可延期项（§4.7.2）。

### 3.4 红线（防止滑向效率优化）

| 绝不做 | 原因 |
|---|---|
| 显示覆盖率百分比 / 覆盖格数 / "点亮进度条" | 玩家会开始算最优布塔，P1 崩 |
| 光源做出"产出 / 能量 / 范围升级"数值 | 光是景观与守护的语义，不是生产资料 |
| 雾开关做成定时切换 / 天气随机轮换 | 隐性计时压力（雾必须是**可自由开关的天气状况**，玩家主控——R-3 同源口径） |
| 鲸背 / 浮标做出"点击奖励" | 恒定循环、与玩家操作无关（同泉州渔船纪律） |

## 6. 验收要点与待确认

### 6.1 验收（对齐 `location-gameplay-design.md` §4.7.1 的 M1–M6）

| # | 门槛 | Cape Cod 的验收判据 |
|---|---|---|
| **M1** | 地形与视听成型 | 缩略图尺寸下**一眼认出**：银灰木瓦 + 红白条纹塔 + 沙丘长浪（水体 wave 三项全表第一是硬辨识物）；§4 参数已套 `LocationProfile` |
| **M2** | 动词成立 | 光锥覆盖判定上线并过**手感验收**（不是"能跑"，是"好玩"）——暗角可读、光束扫掠可感、零暗角时刻可稳定复现 |
| **M3** | 建材齐活 | ≥ 4 种新建材（高地灯塔 / 小灯塔 / 灰木瓦小屋 / 海滩草）+ 复用件改造完成；**主力建材 = 高地灯塔**，必须在内 |
| **M4** | 落成高光可达 | 「零暗角时刻」可稳定复现，且**在夜 / 雾态下可截图**；「凉雾灯塔」画面可稳定复现 |
| **M5** | 引导完整 | 新手目标 + 「选中灯塔 / 守望屋 / 浮标时浮现一句话提示」 |
| **M6** | 分享闭环 | 产品级门槛，四地共用（P 键拍完必须有分享出口） |

**环境态补充验收**：

1. 🔴 **雾的观感判据（唯一判据，非数值）**：任何一态（含雾天档）下，玩家脚下 8 格内的网格必须清晰可辨，看不清就是 bug。
2. 🔴 **夜雾 A/B 顺序**：**先看 Cape Cod 夜（0.0058，全表最浓、夜雾真正的上边界），泉州第二**（回源 §5.1.1.2）。
3. ⛔ **日落两项钉死**：`light_energy 0.75` / `sky_top #4A4A5E` 不动；`sunset_ambient` 填 **0.34**，不得沿用昼档 0.45（回源 §6.2 / §6.2.1）。
4. 🔴 **V2（`fog_disabled` 映射）对本地是三重前提**：光锥贴片、灯火光斑、暗角提示 / 覆盖热力图（颜色编码玩法数据的地面 overlay）**全部依赖它绕雾**——Cape Cod 是四地里最依赖 V2 的地点；V2 未验证前，热力图读数不可信（回源 §5.1.3 / §10.3）。
5. ⚠ **性能 spike 前置**：光锥 mesh 逐帧旋转 + MultiMesh 的实机帧率必须在开工前 spike（口径见 `location-gameplay-design.md` §2.3 末条与 R-4）。
