# 雾港造物记：样板项目需求

## 项目目标
- 做一个原创、单人、3D 海岛聚落自由建造游戏，不复制任何商业游戏的素材或名称。
- 兼具体素式拼搭与微缩景观审美；无需资源采集与战斗即可开始创造。
- Godot 负责游戏状态、网格与交互；Blender 负责可重建的模块资产。
- 同时作为空间计算、撤销命令、数据校验、资产流程与测试方法的学习样板。

## 已设计的玩法
- 22 种建材，分地形、建筑、自然；支持堆叠、旋转、拆除及挖取地形。
- 泉州、圣托里尼、塞舌尔、Cape Cod 四地点分别以“连、悬、叠、照”为构筑动词。
- 可重复组合单元使用六方向接口规则；放置、拆除、旋转和撤销后自动重算邻居并切换衔接形态。
- 有限岛屿边界，多格模型占位，空中建造需要支撑，水面可直接搭地基；圣托里尼允许有侧向锚点的悬挑。
- 撤销/重做最多保留 160 次操作，新操作会清空重做分支。
- 清晨/白昼/日落/夜晚四态、环绕相机、微缩地图、拍照分享、保存和导入导出 JSON。
- 每地点 M1—M6 只统计学习者新增内容，不把预置建筑计作学习成果。

## 约束条件
- Godot 4.7，GL Compatibility / WebGL 2，Web 导出关闭线程依赖。
- 不接公网数据库、不开放多人联机、不改现有平台权限、不启用 EdgeOne 托管。
- 建材数量上限 12000 个原点；世界 X/Z 范围 ±25，一般地点垂直范围 -4 至 20，圣托里尼至 32。
- 不执行导入存档中的代码、文件路径或资源名；使用建材 ID 白名单。
- 存档上限 4 MB；全部通过校验后才原子替换当前世界。
- `.blend` 只作为离线教材；Godot 运行时使用 GLB，不需要安装 Blender。

## 验收标准
- 放置、拆除、旋转、多格占位和撤销重做都真正改变场景，而非只切换 UI。
- 17 种 Blender 模型实际生成并被 Godot 导入；在线生成候选必须通过三角面、法线、原点、尺寸和坐标 QA。
- 四地点存档互相隔离；旧版单岛存档迁移到泉州，坏地点 ID 或越界数据原子拒绝。
- 夜景不得创建 `OmniLight3D`/`SpotLight3D`，使用 emission、光斑和光锥表现。
- 保存后可恢复；未知版本、越界、重叠、错误 JSON 与超大输入均拒绝且不破坏当前作品。
- 模型单测、场景冒烟与真实浏览器交互分层验证；HTTP 200 不代表游戏完成验收。
- 教程只检查可机器验证的事实；设计质量与个人反思由教师/学习者显式确认。

## 交付物
- 完整 Godot 工程、模块化脚本、两组可重复运行的引擎测试。
- Blender 源工程、确定性生成脚本、Tripo/混元 provider、Blender QA、17 种 GLB 与资产清单。
- 可试玩的 Web 导出文件、课程 YAML、分层学习任务、课堂指南。
- 中文字体子集及开源许可证；不使用外部 CDN。

## 不属于本样板的范围
- 不是完整 Minecraft 克隆：没有无限区块流送、战斗、合成、生存经济或联机。
- 不是第一人称角色扮演：采用环绕/平移式建造视角。
- 没有自动检查桥梁可通行性、房屋宜居性或自动教师评分。
- 手机竖屏不是主要目标；建议桌面浏览器或横屏平板。
